# أوردرات ⚡ — رفيق المندوب ونظام مكاتب الشحن

تطبيق ويب متكامل لإدارة عمليات التوصيل، مصمم خصيصاً لمندوبي التوصيل ومكاتب الشحن واللوجستيات (مثل Speedo وغيرها).

## ✨ المميزات الرئيسية
- 👔 **لوحة تحكم مدير المكتب (Office Manager)**: توزيع الأوردرات على المناديب، متابعة خطوط السير على الخريطة، وتقفيل العهدة النقدية (COD Settlement).
- 🛵 **تجربة المندوب بنظامين (Courier Modes)**:
  - **وضع المكتب (Agency Mode)**: استلام وتوصيل أوردرات المكتب وحساب عهدة التسليم.
  - **وضع المندوب الحر (Freelance Mode)**: إدارة الأوردرات الشخصية وحساب صافي الربح المستقل.
- 🗺️ **خرائط ومسارات ذكية مجانية بالكامل**:
  - خريطة تفاعلية بالوضع الليلي مع Leaflet و CartoDB Dark Matter.
  - ترتيب خط السير وحساب المسافة والوقت عبر OSRM API.
  - تحديد موقع المندوب بالـ GPS بضغطة واحدة.
- 📞 **إجراءات الشارع الفورية**: اتصال مباشر، إرسال رسالة واتساب جاهزة، وفتح الموقع في خرائط Google.
- 💼 **محفظة مالية وتقارير يومية**: حساب عمولة المندوب، خصم مصاريف البنزين، ومشاركة تقرير التقفيل عبر واتساب.
- 🔒 **حفظ البيانات بدون خادم**: اعتماد كامل على `localStorage` مع تشفير وسرعة فورية دون الحاجة إلى قاعدة بيانات خارجية.

## 🚀 التشغيل محلياً
```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev

# بناء المشروع للإنتاج
npm run build
```
